# 🌵 astro-archive
> No two shows the same. All of them here.

A vintage-styled static setlist archive for Travis Scott fans.
Built with pure HTML + CSS — no JavaScript, no frameworks.

## What's inside
- Concert setlists from 2018–2024
- Vintage concert poster aesthetic
- Dark theme with CSS animations
- Hosted on vercel

## Built to learn
Semantic HTML · CSS variables · Flexbox · Box model · Google Fonts · GitHub Pages
